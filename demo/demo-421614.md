## 5. Boundary Rule Verification

The Tranche protocol enforces strict, mutually exclusive temporal boundaries between claiming and clawing back:

1. **`claim(id)` Validity Window**:
   - `block.timestamp <= deadline`: Valid. Anyone can claim provided `target.codehash == expectedCodeHash`.
   - `block.timestamp == deadline`: Valid (claim is permitted up to and including the exact second of the deadline).
   - `block.timestamp > deadline`: Reverts with custom error `DeadlinePassed()` (`0x387b2e55`).
2. **`clawback(id)` Validity Window**:
   - `block.timestamp <= deadline`: Reverts with custom error `DeadlineNotPassed()` (`0x02eb3543`).
   - `block.timestamp == deadline`: Reverts with `DeadlineNotPassed()`.
   - `block.timestamp > deadline`: Valid. Anyone can trigger clawback to refund the locked tokens to `refundTo`.
3. **Mutual Exclusivity**:
   - At no timestamp can both `claim` and `clawback` succeed.
   - At the exact boundary second (`block.timestamp == deadline`), `claim` is enabled while `clawback` is strictly blocked.
