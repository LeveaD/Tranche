1. TEMPORAL BOUNDARY SEMANTICS

The protocol enforces strict, mutually exclusive boundaries between claim and clawback:

CONDITION claim(id) clawback(id) GOVERNING RULE
block.timestamp < deadline ALLOWED (if codehash matches) REVERTS (DeadlineNotPassed) Deliverable execution window
block.timestamp == deadline ALLOWED (boundary second) REVERTS (DeadlineNotPassed) Exact second favors claim
block.timestamp > deadline REVERTS (DeadlinePassed) ALLOWED Guaranteed refund window
